Projects

Things I’ve built.

SynthID Check

A Firefox extension that checks images, video and audio for SynthID, the invisible watermark that Google’s AI tools and partners such as OpenAI embed. Drag, right-click or pick media on any page and the original file opens in Google’s SynthID Detector. Unit-tested, with CI and tagged releases on GitHub Actions.

  • JavaScript
  • WebExtensions
  • Firefox
  • GitHub Actions

TotK Atlas

A Korean-language interactive map and guide for The Legend of Zelda: Tears of the Kingdom. It covers the Surface, Sky and Depths layers, shows where items, collectibles and locations are, and has category filters and search with Korean initial-consonant (초성) matching.

  • TypeScript
  • Leaflet
  • Vite
  • HTML/CSS

Personal project, not publicly hosted

Ray Tracer in Java

A port of the ray tracer from Ray Tracing in One Weekend to Java, using only the Java standard library, with a bounding volume hierarchy (BVH) to speed up ray intersections.

  • Java
  • BVH
  • 3D rendering

Caelestia Theme for Spotifast

Makes the Spotifast music player follow the Caelestia desktop’s color scheme. Whenever the wallpaper, scheme or light/dark mode changes, a Python script maps Caelestia’s Material You colors to a Spotifast palette and the player recolors without interrupting playback. Runs as a Caelestia hook or a systemd path unit.

  • Python
  • Shell
  • systemd
  • Linux
